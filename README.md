# ConnectaTel-analysis 📌

## Objetivo del proyecto: 📊
Este análisis tuvo como objetivo contestar preguntas de negocio de una empresa de la comunicación para optimizar y mejorar la oferta a los clientes de acuerdo a sus necesidades para aumentar la satisfacción de los mismos contribuyendo a una mayor retención y atracción de potenciales clientes.

## Datasets utilizados: 🗃
-plans.csv
-users.csv
-usage.csv
-Notebook principal con limpieza, join, análisis, visualizaciones y conclusiones.

## Etapas del análisis: 🔎
-Exploración de datos y estructura de datasets
-Identificación de problemas de calidad de datos (valores inválidos, sentinels, fechas)
-Limpieza de datos
-Resumen estadístico
-Visualización de distribuciones y outliers
-Segmentación de clientes (por edad y por uso)
